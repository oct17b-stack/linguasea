## 语法与用词

- [ko-C1-r02] 日记全用现在时（오늘은 … 모임이 있어요 / 가요）：过去时到 ko-C5-01 才教，C1–C4 的日记、故事都只能用叙述性现在时。母语者读来是否自然？
- [ko-C4-05] 일요일에 일이 생겼어요：过去时比 C5-01 早出现一次，作为固定说法使用，讲解里说明"过去式下一单元再学"。可以吗？
- [ko-C1-04] 바둑을 할 줄 알아요：口语用 하다，标准搭配是 바둑을 두다（讲解里提到）。请确认口语里用 하다 自然。
- [ko-C1-05] 캠핑은 좀 멀어요：省略说法（"露营的地方有点远"）是否自然？
- [ko-C2-04] 이름이 뭐예요?：诊所前台对病人这样问是否太随便？（성함이 어떻게 되세요? 要到 D8 才教。）
- [ko-C6-06] 렌터카를 탈 거예요? / 렌터카는 안 타기로 했어요：用 타다 而不用 빌리다（빌리다 在 C13-03 才教）。口语里可以说 렌터카를 타다 吗？
- [ko-C7-01] 어느 나라 사람이에요?：出租车司机对乘客用不带敬语的 -이에요（-이세요 在 D8-06 才教）。是否过于随便？
- [ko-C8-06] 제가 도와 드릴게요：돕다 只在 A–B 学过固定的 도와주세요（B14-01）。店员这句是否自然？
- [ko-C5-06] 본 지 정말 오래됐어요：按词典把 오래되다 连写，课文生词是 오래。请确认写法。
- [全 C 阶段] 好几个 C 阶段语法点在 A–B 大纲里已经出现过（B7 -고 싶어요、B9 N 동안、B11 -(으)세요/-지 마세요、B16 -러 가요），C 阶段这些课仍按大纲作为语法点讲解（讲得更系统）。是否需要把讲解改成"复习"口吻？

## 泰文转写

- [ko-C3-02] 과목 → ความก：按约定闭音节 ㅗ 省略 โ，但泰国读者可能读成 "ความ-ก"。有更好的写法吗？
- [ko-C3-01] 강의실 → คังอีชิล、[ko-C3-06] 회의 → ฮเวอี、[ko-C8-03] 탈의실 → ทารีชิล：非词首的 의 按实际发音 [이] 转写（同 편의점 พยอนีจ็อม）。请确认。
- [ko-C2-05] 알약 → อัลลยัก、[ko-C2-r01] 진료 → ชิลลโย、[ko-C3-05] 동료 → ทงนโย：ㄹ/ㄴ + y 按学术院写成辅音丛。泰国读者能读对吗？
- [ko-C1-02] 피아노 → พีอาโน、기타 → คีทา：按韩语发音写，没用泰语外来词 เปียโน / กีตาร์（意思栏里有）。可以吗？
- [ko-C8-01] 색깔、검은색、초록색、분홍색：A7 已有 색 สี、까만색 สีดำ、녹색 สีเขียว、핑크색 สีชมพู，所以意思写成 "สี, สีสัน (ภาษาพูด)"、"สีดำ (= 까만색)" 等以便区分。泰语老师看是否自然。
