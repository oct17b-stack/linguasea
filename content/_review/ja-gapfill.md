# 日语课补词（基础词缺口）审校备注

有一批常用基础词在对话和读物正文里反复出现，却从来不是任何一课的词条，所以不进复习，也没有词义（例如 いう 用了 139 课、できる 124 课、おもう 114 课）。这次把全课程 720 课（A–F，含读物）系统查了一遍，提出补成词条的方案，每个词只教一次。本文件只分析、不改课文件；每条可以直接照抄进课里（目标语层 items + 泰语层 items）。

做法：
- 已教词表：全部词条（字母、音节练习除外）。词条本身就是这个词时（辞书形、A–B 的 ます 形、です 形、带 お／ご 前缀）才算教了这个词，它的活用形一起算；短语和复合词条（もう いちど、また あした、もうすぐ、旅行会社、うわさばなし…）只算教了这个整体：正文里同样的字串不算缺口，但其中的单词单独用时算。
- 扫描：用形态分析器（fugashi + unidic-lite）按课程顺序切分全部对话句和读物正文，取词元（辞书形）和读音，与词表对照；纯假名词条另按读音对照（单念的假名容易切错）。去掉助词、助动词、数字、人名地名。只看 2 课以上用到的词，1 课的只留最基础的（おそい）。
- 人工复核：逐个看例句，排除切词错误（つかって 被切成 浸かる、かえって〈帰って〉被切成副词 却って 之类）、同音词条造成的误配（见文末"其他发现"），以及讲解里讲过的纯语法成分。由语法点带出、本身是实词的词（できる、いう、おもう、あげる／もらう／くれる、もう／まだ…）照韩语补词（ko-gapfill.md）的做法补成词条，因为讲解不进复习。
- 位置：放在第一次用到的那一课（已教短语里的出现不算）；那一课已有 7 个词条时，放进同单元首次出现之前最近的、不满 7 个的课；从不放在首次出现之后。按 docs/CONTENT.md，基础词可以作为第 7 个词条。几个词抢同一个位置时，用得多的优先。
- 词条写法：id 照现有写法（小写罗马字，长音按假名写成 ou／uu，同音词加后缀）；text 跟首次出现那课正文的写法：D 阶段以前用假名，E–F 正文已经写汉字的 持つ、立つ、会社、一方、約、込める 用汉字，量词 年 和 日（ひ）照 時／月／日 的写法用汉字加 say；动词用辞书形（这批词首次出现都在 C 阶段以后，不涉及 A–B 的 ます 形）；reading 用赫本式（长音加长音符号）；泰文转写按 content/_review/ja.md 的约定（用脚本按约定转写，再和全课 3,000 多个已有转写对照过写法）；kind 全是 word。泰语词义和全课已有词条、和本表其他词条逐条比对过，没有完全相同的（`npm run dupes -- --target ja --meanings` 应不报）；新 id 和已有 id、同字同读音的已有词条也都查过，没有重复。
- 结果：建议新增 60 个词条，分布在 56 课（B 阶段 1 个、C 16 个、D 14 个、E 10 个、F 19 个）；另有 1 个按规则放不进去（はんぶん，见后）。以下 8 课会变成 7 个词条：D1-06、D8-04、E1-05、E9-01、E12-06、F2-01、F3-01、F6-06。

## 其他发现、拿不准的地方

- 同音词条会让"是否已教"的检查看走眼：ja.koto 是 古都（E14-r01），ja.ji 是 時（…じ），ja.nichi 是 日（…にち），ja.kata 是 かた（肩），所以 こと（220 课）、とき（125 课）、ひ（42 课）、方（かた，"那位"或"…的方法"）按读音对照时都像"已教"。前三个已补；かた 是敬语和 〜かた 语法，没补。
- 一半左右的词第一次出现就在讲解它的语法课（C1-05 できる、C3-04 どちら、C9-06 ちがう、C12-04 かかる、C13-02 おわる、C14-01 いう、C15-01～03 あげる／もらう／くれる、D1-01 おもう、D3-02 まだ、E1-05 たのむ），词条放在语法课本身，讲解不用改，只加词条和泰语词义。
- もう：第一次单用在 B10-05、B15-03、D1-01（もう ひとつ／もう いちまい ＝"再一个"），"已经"的意思从 D3-02 起（D3-02 讲解 もう 〜ました）；词义两层都写了，请泰语老师看措辞。
- やる：第一次是 D6-r02 的感叹 やった！，一般用法（やって みる、どうやって…）从 F1-01 起。如果觉得 D6-r02 放词条太早，可以把 やった！当套话，词条改放 F1-01（现有 5 个词条）。
