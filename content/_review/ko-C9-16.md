## 词条和词义

- [ko-C11-01] 운동하다 ko.undong-hada 和 B5-02 的 운동해요 ko.undonghaeyo 是同一个词的两种形式，复习题可能把两者同时当选项；泰语词义加了"รูปพจนานุกรมของ 운동해요"。同类：매진되다 / 매진（B16）、예매하다 / 예매（B16）、배달하다 / 배달（B12）、환전하다 / 환전（B13）、서명하다 / 서명（B10）、고장 나다 / 고장（A15）、따라 하다 / 따라 하세요（A1-06）。建议规划考虑合并或换词。 ✅ resolved: 词条照大纲保留（id 不改）。按 C1–C8 第二轮约定，词义括号里不写韩语词（"看义选词"题会把它当成答案）：운동하다 改为 เล่นกีฬา, ออกกำลังกาย (รูปพจนานุกรม)。名词和 하다/되다 动词靠泰语词性区分：예매하다 ซื้อตั๋วล่วงหน้า, จองตั๋ว ↔ 예매 การจองตั๋วล่วงหน้า (…)、매진되다 ขายหมด (กริยา ใช้กับตั๋ว บัตร) ↔ 매진 ขายหมดแล้ว、따라 하다 เลียนแบบ, ทำตาม (แบบอย่าง) ↔ 따라 하세요 พูดตามนะ (…)；환전하다、배달하다、서명하다、고장 나다 原词义已能区分。`npm run dupes -- --target ko --meanings` 无重复。
- [ko-C16-04] 다운로드하다 / 다운로드하세요 / 다운로드했어요：照大纲读 daunrodeu-（外来词的 ㄴ+ㄹ 不按流音化写），泰文 ทาอุนโรดือฮาดา。实际读 [다운로드]、[다운노드] 还是 [다울로드]？请老师定，生成配音后再听一遍。
