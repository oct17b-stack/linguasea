## 写法说明（已按 content/_review/zh.md 的「约定」统一）

- 拼音不加引号；万 分写（liǎng wàn、èrshí wàn、yī wàn wǔqiān），百、千 连写；第 + 数字 加连接号。
- 趋向补语紧跟动词时写轻声（zhàn qilai、zǒu guolai、xiěshang、cúnjin）；单用的趋向动词写本调（chūlái、shàngqù）。想起 按 D13 的写法保留 xiǎngqǐ。
- 单音节动词 + 完 / 好 / 到 / 掉 / 坏 连写（xiěwán、dúhǎo、huādiào、yònghuài），双音节动词分写（tǎolùn wán、zhǔnbèi hǎo）；动词 + 到 + 处所分写（bān dào、sòng dào）。
- 近义词的词义都加了括号区分（职位 / 岗位、签 / 签字 / 签署 / 签约、人民 / 群众 / 老百姓、发布 / 公布 / 宣布、依照 / 按 / 据 等）。

## 问题

- [zh-F1-06] 总而言之 zǒng ér yán zhī、由此可见 yóu cǐ kě jiàn：拼音照大纲分写，正词法一般连写（zǒng'éryánzhī），全课的成语写法是否统一成一种？ ✅ resolved: 保留分写：全课的成语都按音节或按词分写（rù xiāng suí sú E1-01、yī jiàn zhōng qíng E7-02、bù zhī bù jué E10-r01、huǎngrán dàwù F8-05），已经一致。
- [zh-F2-01] 「据新闻报道，目前在中国学习的泰国学生有两万多人」：是虚构新闻里的数字（大致符合近年情况），是否要改成更笼统的说法？ ✅ resolved: 保留：近年在华泰国留学生确实是两万多（F15-r01 也这样说），又是故事里报纸的说法。
- [zh-F2-05] 「中泰一家亲」译成泰国常用口号「จีนไทยใช่อื่นไกล พี่น้องกัน」；「一九七五年开始有外交关系」是事实，但没用「建交」（建立 F10 才学），说法是否自然？ ✅ resolved: 中泰一家亲 是 F15-r01 的词条，本课和 F2-r01 不再提前用：奶奶的话改为「中国和泰国像一家人一样」（泰语照样译成 จีนไทยใช่อื่นไกล พี่น้องกัน），F2-r01 志愿者改说「我们是一家人」；「一九七五年开始有外交关系」是 建交 的通俗说法，自然，保留。
- [zh-F2-r02] 大兴机场到曼谷的新航线、票价便宜百分之二十都是虚构的，是否需要说明？ ✅ resolved: 不用说明：读物是王明转发的一条消息，没有真实航空公司；另把「以前我一直想去曼谷」改为「一直想再去曼谷看看」（王明 A–B 在曼谷留学过，E13-r02 也这样写）。
- [zh-F3-03 / zh-F3-06 / zh-F3-r01] 小南写的正式邮件和回函，泰语译文用「ดิฉัน」（正式的女性自称），对话仍用「ฉัน」，这样是否合适？ ✅ resolved: 保留：书面的正式邮件、回函用 ดิฉัน 是泰语的正常文体；约定的 ฉัน 只管对话，对话里仍是 ฉัน。
- [zh-F3-r01 / zh-F5-r02] 邮件格式里「此致」「敬礼！」、署名、日期各算一句（配音会单独念）；泰语把 此致 / 敬礼 对应成「จึงเรียนมาเพื่อโปรดพิจารณา」「ขอแสดงความนับถือ」，是否合适？ ✅ resolved: 保留：泰国公文的结尾正是「จึงเรียนมาเพื่อโปรดพิจารณา」+「ขอแสดงความนับถือ」，功能对应；署名、日期单独成句不影响理解。
- [zh-F3-r02] 通知里用了书面语 时、因（报到时、如因个人原因），之前没有作为词条教过，读物加了讲解；是否可以接受？ ✅ resolved: 保留：这是通知的正式写法，读物讲解已说明（报到时 = 报到的时候，如因 = 如果因为）。
- [zh-F4-05] 实习翻译每月一万五千泰铢、正式工作试用期三个月，是否符合曼谷中资公司的一般情况？ ✅ resolved: 合理：泰国试用期一般不超过 119 天（三四个月）；会中文的实习翻译每月一万多泰铢偏高但说得过去。
- [zh-F5-03 / zh-F5-r01] 椰子每个十三块五人民币、泰国香米每吨九百五十到一千美元、越南大米六百美元：只求大致合理，是否需要调整？ ✅ resolved: 大致合理：泰国香米近年出口价每吨约一千美元，越南大米五六百美元；椰子十三块五是批发价，教学对话可以接受。
- [zh-F6-05] 骗子 piànzi：大纲没有这个词，但本课语法例句「我上了骗子的当」要用，所以加成本课第 6 个词条（zh.pian-zi，npm run dupes 无重复），是否保留？ ✅ resolved: 保留（本课语法例句「上了骗子的当」需要；全课程没有别的 骗子 id，dupes 无重复）。
- [zh-F6-r02] 「钱是省出来的」作为「中国有句老话」是否合适？ ✅ resolved: 这是常说的俗话，不算「老话」，改为「中国人常说」。
- [zh-F7-01 / zh-F7-r01] 北京骑自行车闯红灯、骑电动自行车逆行一般罚款二十元，骑电动自行车不需要驾照：按目前北京的规定写的，请核对。 ✅ resolved: 符合北京现行规定：非机动车闯红灯、逆行罚款二十元；电动自行车属于非机动车，要上牌，不需要驾驶证（读物写的是「这种电动车」）。
- [zh-F7-06] 泰国禁止带电子烟入境、下午两点到五点和佛教节日不卖酒、部分海滩禁烟：按近年规定写的（讲解 2 也有），上线前请核对是否仍然有效（卖酒时间近年有放宽的讨论）。
- [zh-F8-05] 北京饺子按两卖、「一两大概有六个」，以及要说「二两」不说「两两」：是否准确？ ✅ resolved: 准确：北方饺子按两卖（一两五六个到八个不等），重量说「二两」不说「两两」。
- [zh-F1-04] 「这一点谁也不能否认」「那你能否认……吗？」里出现「能否认」，和 F3-02 教的 能否 字面相同，学生会不会看错？句子本身是自然的，暂时保留。 ✅ resolved: 保留：「能否认」是 能 + 否认，拼音 néng fǒurèn 分写，能否 到 F3-02 才教，不会看错。
- [zh-F1-05] 「我叔叔的女儿刚上大学」接着 E5 的情节（王明叔叔的女儿参加高考），没有用 堂妹（未学过），是否自然？ ✅ resolved: 自然（口语常说「我叔叔的女儿」）；时间也接得上：E5 她「明年六月」高考，F 阶段在那之后。
