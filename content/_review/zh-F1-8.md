# 中文课 F1–F8（F 阶段前半）审校备注

写课时拿不准、需要母语老师确认的地方。格式：`- [课号] 词条/句子：问题`。

## 写法说明（已按 content/_review/zh.md 的「约定」统一）

- 拼音不加引号；万 分写（liǎng wàn、èrshí wàn、yī wàn wǔqiān），百、千 连写；第 + 数字 加连接号。
- 趋向补语紧跟动词时写轻声（zhàn qilai、zǒu guolai、xiěshang、cúnjin）；单用的趋向动词写本调（chūlái、shàngqù）。想起 按 D13 的写法保留 xiǎngqǐ。
- 单音节动词 + 完 / 好 / 到 / 掉 / 坏 连写（xiěwán、dúhǎo、huādiào、yònghuài），双音节动词分写（tǎolùn wán、zhǔnbèi hǎo）；动词 + 到 + 处所分写（bān dào、sòng dào）。
- 近义词的词义都加了括号区分（职位 / 岗位、签 / 签字 / 签署 / 签约、人民 / 群众 / 老百姓、发布 / 公布 / 宣布、依照 / 按 / 据 等）。

## 故事线（F1–F8）

春季学期在北京：课堂辩论（F1）、和王明吃早饭聊新闻（F2）、申请另一所大学国际学院的暑假翻译班（F3，7 月 1–14 日）。7 月 15 日回曼谷，7 月 18 日在一家做泰国水果和大米出口的中国公司面试，暑假当实习翻译到 8 月底（F4–F5）；王明暑假来曼谷玩，住在小南家（F2-r02、F4-06、F8-r02）。9 月回北京（F6–F8）。F7 的泰国朋友是 E10 里刚到北京的泰国男生（泰语里叫她 พี่）。

## 问题

- [zh-F1-06] 总而言之 zǒng ér yán zhī、由此可见 yóu cǐ kě jiàn：拼音照大纲分写，正词法一般连写（zǒng'éryánzhī），全课的成语写法是否统一成一种？
- [zh-F2-01] 「据新闻报道，目前在中国学习的泰国学生有两万多人」：是虚构新闻里的数字（大致符合近年情况），是否要改成更笼统的说法？
- [zh-F2-05] 「中泰一家亲」译成泰国常用口号「จีนไทยใช่อื่นไกล พี่น้องกัน」；「一九七五年开始有外交关系」是事实，但没用「建交」（建立 F10 才学），说法是否自然？
- [zh-F2-r02] 大兴机场到曼谷的新航线、票价便宜百分之二十都是虚构的，是否需要说明？
- [zh-F3-03 / zh-F3-06 / zh-F3-r01] 小南写的正式邮件和回函，泰语译文用「ดิฉัน」（正式的女性自称），对话仍用「ฉัน」，这样是否合适？
- [zh-F3-r01 / zh-F5-r02] 邮件格式里「此致」「敬礼！」、署名、日期各算一句（配音会单独念）；泰语把 此致 / 敬礼 对应成「จึงเรียนมาเพื่อโปรดพิจารณา」「ขอแสดงความนับถือ」，是否合适？
- [zh-F3-r02] 通知里用了书面语 时、因（报到时、如因个人原因），之前没有作为词条教过，读物加了讲解；是否可以接受？
- [zh-F4-05] 实习翻译每月一万五千泰铢、正式工作试用期三个月，是否符合曼谷中资公司的一般情况？
- [zh-F5-03 / zh-F5-r01] 椰子每个十三块五人民币、泰国香米每吨九百五十到一千美元、越南大米六百美元：只求大致合理，是否需要调整？
- [zh-F6-05] 骗子 piànzi：大纲没有这个词，但本课语法例句「我上了骗子的当」要用，所以加成本课第 6 个词条（zh.pian-zi，npm run dupes 无重复），是否保留？
- [zh-F6-r02] 「钱是省出来的」作为「中国有句老话」是否合适？
- [zh-F7-01 / zh-F7-r01] 北京骑自行车闯红灯、骑电动自行车逆行一般罚款二十元，骑电动自行车不需要驾照：按目前北京的规定写的，请核对。
- [zh-F7-06] 泰国禁止带电子烟入境、下午两点到五点和佛教节日不卖酒、部分海滩禁烟：按近年泰国的规定写的，请核对是否仍然有效。
- [zh-F8-05] 北京饺子按两卖、「一两大概有六个」，以及要说「二两」不说「两两」：是否准确？
- [zh-F1-04] 「这一点谁也不能否认」「那你能否认……吗？」里出现「能否认」，和 F3-02 教的 能否 字面相同，学生会不会看错？句子本身是自然的，暂时保留。
