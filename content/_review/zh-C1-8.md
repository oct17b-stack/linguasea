# 中文课 C1–C8 审校备注

写课时拿不准、需要母语老师确认的地方。格式：`- [课号] 词条/句子：问题`。审校能确定的已改好并标「✅ resolved」，没标的留给母语老师终审。

## 写课时的处理（供终审核对）

- 故事线：A–B 阶段王明在曼谷待过（B1-r01、B5-01、B14-r01），但大纲把 C6-r02 写成「王明第一次去泰国」，C5、C7 的情景也像他从没去过泰国。课文按 A–B 已写的内容处理：C6-r02 写成回忆「去年王明第一次去泰国」（就是小南带他逛曼谷那次），C5-05、C7-05 写成他计划再去泰国（清迈、十二月），C5-03 提问的人改成小南的同学（女，c）。AI 口语情景（C5、C7 的 scenario）可能也要相应调整。
- 时间线：C1–C8 按一个学期排：九月开学（C3-r01 日记 9 月 2 日）→ 十月长城（C6-r01、C6-05）→ 两个月后天冷（C6-06 把大纲例句的「三个月」改成「两个月」，好接上 C7 的秋天）→ 冬天、下雪、买大衣、公司新年晚会（C8）。
- 「了」：C6、C7 之前只用了固定说法（太好了、好多了、坏了、有了、怎么了、知道了、打错了、对了）和 C5-02 的「多了」，没有用「动词 + 了」叙述过去。

## 问题

- [zh-C3-05] 开会 kāihuì：大纲没有这个词，但本课语法例句和对话都要用，新增为词条 `zh.kai-hui`（`npm run dupes` 无重复）。是否保留？ ✅ resolved: 保留。大纲的语法例句「我跟同事一起开会」本身就要用，是大纲漏了；全课没有别的 id，后面 C13-02、F5-01 的课文也用到 开会。
- [zh-C3-r01] 9 月 2 日的日记写「今天是我来北京留学的第一天」，而 C1、C2 里小南已经在北京上课了。按「回头看的第一篇日记」处理，读者能接受吗？ ✅ resolved: 保留（日记带日期，是开学第一天写的）；泰语导语改为「…บันทึกประจำวันที่น้ำเขียนไว้ในวันแรกที่มาเรียน… (ต้นเดือนกันยายน)」，交代这是九月初的日记。另外小南 B6、B10 去过北京，「我对北京的第一印象」改为「我对这个学校的第一印象」，问题 3 跟着改。
- [zh-C4-05] 这个座位有人吗？：「有人」在 D5-05 是词条 yǒurén；这里按「有 + 人」分写 yǒu rén。是否合适？ ✅ resolved: 保留 yǒu rén（动宾结构，《现汉》不立「有人」条，HSK 教材也分写）。D5-05 的词条读音不在本范围，已报告给 D 阶段。
- [zh-C5-06] 曼谷「差不多一千万」人（大曼谷地区；登记人口约 550 万）、泰国「差不多七千万」：取整是否可以？ ✅ resolved: 保留：中文媒体常说曼谷约一千万人（含常住外地人口），泰国约七千万（联合国估算约 7100 万），对话里用「差不多」可以接受。
- [zh-C6-r02] 按摩 泰文注音写 อั้นหมัว，避开 อั้นหมอ（หมอ = 医生）；A–B 阶段 b/p/m/f 后的 o 写 อ（ป๋อ、ม่อ、ฝอ），D 阶段也有 หมัว（模仿）。用哪种？ ✅ resolved: 按 A–B 一音一写：零声母 an 写 อาน、b/p/m/f 后的 o 写 อ → 按摩 อ้านหมอ（和 หมอ 同形，属于约定里 ไม่、หมา 那类已接受的同形）；按时 也改为 อ้านสือ。
- [zh-C4-02] 打错了 注音 ต่าชั่ว เลอ：ชั่ว 是泰语词（坏），但这是泰国教材写「错」的通行写法（不错 ปู๋ชั่ว）。是否保留？ ✅ resolved: 保留，A–B 的 错 都写 ชั่ว。
- [zh-C8-05] 帅 注音 ซ่วย：字形接近口语 ซวย（倒霉），但「帅哥 ซ่วยเกอ」是常见写法。是否保留？ ✅ resolved: 改为 ไซว่，和 A–B 的 uai 写法一致（快 ไคว่），也避开了 ซวย。
- [zh-C7-06] 极了：大纲词条读音 jíle（连写），A16-06 的 好极了 写 hǎo jí le。全课要不要统一？ ✅ resolved: 按前面的 A16-06 统一为 jí le，注音 จี๋ เลอ，对话同步。F11-r01 的 gāoxìng jíle 不在本范围，已报告。
- [zh-C8-05] 什么样的：按 怎么样 zěnmeyàng 的写法连写为 shénmeyàng；HSK 教材有时写 shénme yàng。用哪种？ ✅ resolved: 保留 shénmeyàng：C–F 各阶段都连写，和 zěnmeyàng 一致。
- [zh-C2-01] 疼 / 痛（B16-02）是同义词，词义写成「ปวด / เจ็บ (ภาษาพูด)」和「เจ็บ / ปวด (วางหลังอวัยวะ)」来区分。出题时会不会两个都像正确答案？ ✅ resolved: 疼 的词义改为「ปวด / เจ็บ (ภาษาพูด ใช้บ่อยกว่า 痛)」，词义里点名 痛，两个同时出现在选项里也分得清。
- [zh-C8-r01] 「打八折」：读物加了一条讲解（付 80%，即减 20%），读物本来一般不带讲解。是否保留？ ✅ resolved: 保留。App 的读物也显示讲解（B1-r01 等也有），打折 是本读物的词条，打八折 泰国学生容易理解反，需要这一条。
- [zh-C1-04] 晚会 / 演唱会 / 音乐会（C4-r02）/ 演出 / 表演 / 节目：词义分别写成「งานรื่นเริงตอนค่ำ」「คอนเสิร์ต (ของนักร้อง)」「การแสดงดนตรี (เปียโน วงดนตรี ฯลฯ)」「การแสดงบนเวที (ทั้งรายการ)」「แสดง / การแสดง (ร้อง เต้น ฯลฯ)」「รายการ」。区分是否清楚自然？ ✅ resolved: 区分清楚，保留。另把对话改成「那天也有一个演唱会」，不再像是学校里办的 300 块的演唱会。
- [zh-C1-r02] 学校旁边有一个卡拉OK：大陆口语里这种店多叫「KTV」，大纲词条是 卡拉OK；把 卡拉OK 当店名、用量词 个，是否自然？
- [zh-C7-04] 暖和 注音 หนว่านฮัว：按 A–B 把 uan 统一写成 -วาน（关 กวาน、算 ซว่าน、短 ตว่าน），n 声母三声要加 ห，写成 หนว่าน；泰国读者看着是否别扭（原来是 หน่วน）？
