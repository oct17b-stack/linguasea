- 意思容易混的词条加了括号区分：맞아요 ถูกต้อง, ถูกแล้ว（네 是 ใช่）、파란색 สีน้ำเงิน / 하늘색 สีฟ้า、테이블 โต๊ะ（โต๊ะกินข้าว, โต๊ะในร้าน）/ 책상 โต๊ะเรียน、욕실 ห้องอาบน้ำ / 화장실 ห้องน้ำ。

需要确认：

- [ko-A1-05] 안녕! 잘 지내요?：同龄朋友（남 和 민준 都 20 岁）用 안녕 打招呼、后面仍用 해요体。课程只教 해요体，所以没有改成 잘 지내?。这种混用是否自然？
- [ko-A1-05] 对话：민준 在打工（네, 잘 지내요. 잠깐만요!），남 用 수고하세요 告别，민준 回 고마워요. 잘 자요!。场景只靠译文 ทำงานดี ๆ นะ 暗示，够清楚吗？对平辈朋友说 수고하세요 是否自然？
- [ko-A1-06] 질문 있어요! '마이펜라이' 한국어로 뭐예요? / '괜찮아요'예요.：用韩文转写的泰语 마이펜라이（ไม่เป็นไร），配音按韩语读；回答用"引用 + 예요"，괜찮아요예요 连读略拗口，而且 이에요/예요 到 A3-01 才正式讲（本课讲解只点到"คำนั้น + 예요"）。是否可以接受？
- [ko-A3-06] [ko-A9-03] [ko-A9-04] 한국어：词条在 [ko-B1-04] 才列出，但 A1-06 的短语 한국어로 뭐예요? 已经出现并在讲解里说明 한국어 = ภาษาเกาหลี，A3-06 讲解也讲了"国名 + 어"，所以对话里直接用了 한국어（大纲 A9-03 的例句也这样用）。是否接受，还是应该把 한국어 提前成 A 阶段的词条？
- [ko-A3-06] 영어도 말해요? / 태국어, 영어 말해요：按大纲用"语言 + 말해요"。母语者口语更常说 영어 해요 / 영어 할 줄 알아요，但 해요 在 B5-02 才教。保留？
- [ko-A3-06] 조금 的词义 เล็กน้อย, นิดหน่อย 和 [ko-B3-03] 좀 的 หน่อย, นิดหน่อย 重叠（좀 本来就是 조금 的缩略），复习时两者同时出现在选项里会难分。建议把 B3-03 的 좀 改成 หน่อย（รูปย่อของ 조금 ใช้ขอร้องให้นุ่มนวล）之类（B3-03 不在本次范围，未改）。
- [ko-A4-06] 노래 เพลง, การร้องเพลง 和 [ko-B1-04] 음악 ดนตรี, เพลง 都含 เพลง，建议把 음악 改成 ดนตรี（B1-04 未改）。
- [ko-A4-05] 피자 พีจา、[ko-A10-02] 소파 โซพา、[ko-A10-06] 아파트 อาพาทือ：外来词按韩语发音转写，没用泰语外来词本身的写法（พิซซ่า、โซฟา、อพาร์ตเมนต์），免得学习者照泰语读。请确认。

- [ko-A5-06] 칠 호예요. 삼 층이에요.：房号按大纲用 칠 호（백 到 B3-01 才教，所以没有写 삼백칠 호）。"三楼七号房"在宿舍里是否自然？
- [ko-A6-05] 泰文转写用了泰国通行写法：김밥 คิมบับ、떡볶이 ต็อกบกกี（学术院 ต็อกปกกี）、삼겹살 ซัมกยอปซัล（学术院 ซัมกย็อบซัล）、냉면 แนงมยอน（学术院 แน็งมย็อน，与 라면 รามยอน 一致）。请确认。

- [ko-A7-01] 시계 무슨 색이에요? → 빨간색, 파란색, 노란색이에요.：用来问"有哪些颜色"（무슨 색 있어요? 要等 [ko-B1-04] 的 있어요）。母语者听来是否自然？
- [ko-A8-02] 누구 거예요? / 제 거예요：口语多读 [꺼]，泰文转写照 [ko-B3-04] 다른 거 ทารึน คอ 的先例写 คอ（นูกู คอเยโย、เช คอเยโย），讲解里说明口语读 꺼。要不要改成 กอ？
