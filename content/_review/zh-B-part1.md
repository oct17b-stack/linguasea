# 中文课 B 阶段第一部分（B1–B6 第 05、06 课和读物 r01，B7–B10 全部）审校备注

AI 初稿，以下是拿不准、需要母语老师（汉语 / 泰语）确认的地方。约定沿用 `zh.md`：拼音写本调（不、一 也写 bù、yī，正反问 要不要 写 yào bù yào，和 A7-03 是不是 一样），不、一 的变调只写进泰文注音，轻声写成不带声调符号的平声，量词 个 在句中写 ge。对话只用课程顺序里已学的词：B1 还不能用 去、在、学校、看、回、可以 等后面才教的词（可以 从 B2-02 起，去、在、学校 从 B3 起，看、回 从 B4 起），所以前几个单元的情节比大纲略作调整（见下）。大纲词条照抄，没有新增词条。

## 情节和大纲的出入

- [zh-B1-r01] 大纲写王明「请一天假，提早回家」，但 回（B4-05）、去（B3-04）、了（B4-r01）都还没教，改成：他的父母明天来曼谷，所以他明天 请假；前天 用在「前天我爸爸妈妈说，他们想来曼谷」。日期用汉字写 一月一日（课程正文不用阿拉伯数字），讲解里说明实际常写 1月1日。这样改可以吗？
- [zh-B2-r01] 商场告示：「商场时间：十点——二十二点。」真实告示写 营业时间 10:00—22:00，但 营业、到 还没教，所以用破折号表示"到"，并在讲解里说明 24 小时制（二十二点 = 晚上十点）。可以接受吗？大纲的「试衣服以前先问店员」因为 先、以前 在 B4-06 才教，改成「想试衣服，请和服务员说」。
- [zh-B3-r01] 大纲写书店在「学校大门对面」，大门 在 B10-01 才教，改成 学校对面。
- [zh-B6-r01] 大纲写「坐船去寺庙」，寺 / 寺庙 还没教，终点改成 公园；写成「我和王明第一次坐船」（两人都是第一次坐昭披耶河快船）。第一次（大纲语法）在 C6-05 才作为词条教，这里按大纲语法使用，第二次 由 第一（A4-06）类推。可以吗？
- [zh-B8-04] 大纲语法写「跟 + 人 + 见面」，但 跟 是 B9-04 的词条，对话改用「和你见面」，讲解里提一句口语也说 跟。
- [zh-B10-r01] 运动会、跑步、比赛 都还没教，告示写成「这个星期五下午，我们班去操场跑」，再分男生 / 女生 / 最后老师和同学一起跑。见 单用不是词条，按大纲语法「在 + 地点 + 见」使用（讲解里说明）。

## 用词和读音

- [zh-B1-05] 太……了（太早了、太晚了）里的 太 单用不是词条，按大纲语法使用，讲解里和 太好了 对照说明。
- [zh-B2-05] 「一块钱是多少泰铢？——五泰铢吧。」实际汇率约 4.5–5 泰铢，用 吧 表示估计。可以吗？
- [zh-B3-05] 到路口（到 是 B6-04 的词条）和单用的 左、右 都按大纲语法使用，讲解里说明 到 = ถึง。
- [zh-B5-06] 「哈哈，鸭子真好笑！」：好笑 按大纲语法「真好笑」使用（不是词条），哈哈 拼音写 hāhā。
- [zh-B5-r01] 下大雨 把已学的 下雨 拆开，讲解里说明。
- [zh-B8-01] 喂 按大纲读 wéi（《现汉》标 wèi，接电话时多读阳平），讲解里说明。请抽听配音：TTS 单念 喂 可能读成 wèi。对话没有念电话号码，"1 读 yāo"只在讲解里说。
- [zh-B9-01] 唱个中国歌 / 唱一个：唱 单用不是词条（来自 唱歌 + 歌），讲解里说明 唱歌 = 唱 + 歌；个 是口语用法。
- [zh-B9-02] 打什么球：把 打球 拆开，讲解里说明 打 = ตี、球 = ลูกบอล。王明 是北京人，说 玩儿（wánr），词条仍是 玩。
- [zh-B9-r01] 「你会唱歌、会吉他吗？」：大纲要求避开 弹，所以用 会 + 技能名词（同 B9-05「我会武术」）。会吉他 是口语说法，标准说法是 会弹吉他。是否自然？「大家一起唱，一起跳」里 跳 指跟着音乐蹦（跳舞 在 C1-01 才教）。
- [zh-B10-05] 功课 指作业（大陆口语多说 作业，C3-01 才教），按大纲词条保留。
- [zh-B10-06] 上美术课：把 上课 拆开，讲解里说明。

## 泰语

- [zh-B9-01] 爱好 的泰文注音写 อ้ายฮ่าว，不用自动拼出的 ไอ้ฮ่าว（ไอ้ 在泰语里是粗鲁的称呼前缀），和 A11-05 爱 อ้าย 一致。另：[zh-E2-r02] 有一个词条注音是 เร่อไอ้，建议同样把 爱 写成 อ้าย。
- [zh-B7-06] 欢迎光临 的注音跟 A1-06 欢迎 ฮวนอิ๋ง 保持一致，写 ฮวนอิ๋ง กวางหลิน。但全课有两处不统一：huan 有 ฮวน（欢迎）和 ฮวาน（喜欢 สี่ฮวาน）两种写法；阳平 yí/yín/yíng 有 อิ๋…（欢迎 อิ๋ง）和 หยิ…（银行 หยินหาง）两种写法。建议终审时统一。
- [zh-B6-r01] 次 cì 注音 ชื่อ（和泰语"名字"同形）、[zh-B9-r01] 跳 tiào 注音 เที่ยว（和泰语"玩、旅行"同形）、[zh-B7-02] 啤酒 注音 ผีจิ่ว（ผี = 鬼）：都是泰国教材的通行写法，不粗俗，保留。
- [zh-B1-r01][zh-B2-05] 日 / 号、元 / 块、角 / 毛 意思相同，词义靠括号区分（ภาษาเขียน / ภาษาพูด）；多久 和 多长时间 也是同义词，词义写成 นานแค่ไหน (คำสั้น ๆ ภาษาพูด) 和 นานเท่าไร。自动出题时同时出现可能难分。
