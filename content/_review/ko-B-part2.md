# 韩语课 B 阶段第二部分（ko-B11 … ko-B16）审校备注

AI 初稿（42 课：36 课 + 6 篇读物），未经母语老师审校。词条全部照大纲（id、文字、读音、kind 未改），没有新增词条；`npm run validate -- --target ko --only 'ko-B1[1-6]-'` 通过，`npm run dupes -- --target ko` 无重复。泰文转写按 content/_review/ko.md 的约定，下面只列拿不准或偏离大纲的地方。

## 故事线（按协调说明调整，请确认）

- [ko-B11 … ko-B16] 按最新人物设定（B 阶段 น้ำ 是女生、住在曼谷），大纲里放在韩国的场景改成：B11–B12 在曼谷（同学민준、이 선생님、曼谷的韩国餐馆），B13–B16 是寒暑假去韩国旅行（민준 同时回国，所以 B13-01 他说 저도 다음 주에 한국에 가요，B14-06、B15、B16 他在场）。
- [ko-B11-03] 大纲是药店药剂师对话；曼谷的药剂师不会说韩语，改为 민준 拿出自带的韩国药（저한테 한국 소화제가 있어요），词条和"하루에 세 번"都保留。
- [ko-B12-01] 小吃摊不报价（曼谷不会用韩元，바트 到 C10-05 才教），以 맛있게 드세요 收尾；[ko-B12-04] 外卖费回答改成 배달비는 없어요（问句 배달비가 얼마예요? 保留）。外卖店接受韩语电话订餐（曼谷韩国城）是否可信？
- [ko-B13-03] 大纲是巴士站售票员 + 서울에서 부산까지，但 서울/부산 在 B13-04 才教。改为火车站工作人员，目的地用"指着地图说 여기까지"，N에서 N까지 用 기차역에서 터미널까지；讲解补充巴士站上车处叫 타는 곳。
- [ko-B13-04] 原来写成老师问"서울이 좋아요?"（暗示住在首尔），改为民宿老板问 서울 여행 어때요?
- [ko-B14-03]、[ko-B14-r01] 大纲是宿舍管理员 / 宿舍告示，改为旅行中的民宿：203 号房、"민박 앞 편의점"，两课房号一致。

## 句子和用法

- [ko-B11-01] 감기에 걸렸어요、[ko-B13-02] 예약했어요、[ko-B16-05] 눈물이 나요：按大纲当固定说法用在对话里（걸리다、나다 未单独教），讲解里说明"先整句记"。可以吗？
- [ko-B11-02] 배탈이에요：口语更常说 배탈 났어요（过去式 + 나다 都还没教），暂用 배탈이에요。
- [ko-B11-03] 하루에 세 번 먹어요：用 먹어요 说明服药次数（드세요 到 B11-r01 才作为词条出现）。
- [ko-B12-03] 족발 일 인분, 보쌈 일 인분：大纲要求练 인분；实际 족발 多按 소/중/대 卖，是否改说法？
- [ko-B12-r01] 读物：大纲说三条评论（第三条感谢骑手冒雨送餐）。비 要到 C7 才教，删掉"下雨"；限 6 句、2 段，第二段的辣海鲜面评论和感谢骑手读起来像同一个人写的；词条 리뷰 只出现在标题、导语和讲解里，正文没出现。请确认能接受。
- [ko-B15-r01] 大纲的三个习俗里"双手递东西"没写进去（주다 的活用还没教，且限 6 句）；"一开始觉得奇怪"用 처음에는 정말 놀랐어요（固定过去式）+ 지금은 안 이상해요 表达。
- [ko-B16-r01] 大纲的 -고 싶어요 用在最后一句 또 보고 싶어요；"제 평점은 별 다섯 개, 강추예요!"用逗号连成一句（评论文体）。
- [ko-B14-01] 경찰 아저씨, 빨리 와 주세요!：路人叫警察用 경찰 아저씨，是否自然？
- [ko-B15-04] 민준 的弟弟叫 남 "누나"（男孩叫比自己大的女生），讲解顺带说明女孩叫 언니。

## 读音（RR）

- [ko-B12-01] hotteokhago、[ko-B12-02] tangsuyukhago、[ko-B12-03] jumeokbaphago、[ko-B16-03] maen aphago：按 ko.md 约定"名词 + 하고 保留 h"（同 baphago）；谓词照 RR 写送气（yeyakaesseoyo、kkaekkeutaeyo）。
- [ko-B11-r01] 물약은 → mullyageun（ㄴ 添加 + 流音化，与词条 mullyak 一致）。

## 泰文转写

- [ko-B11-r01] 물약 → มุลลยัก：[물략]，按 ㄹㄹ → ลล（同 몰라요 มลลาโย）写；也可写 มุลยัก。
- [ko-B11-06] 가려워요 → คารยอวอโย，[ko-B15-02] 기다려요 → คีดารยอโย：本来就有的"ㄹ + ㅕ"按学术院写 รย（约定 4），但前面是开音节，泰国读者可能把 คาร、ดาร 读成 คาน、ดาน（与 วอรโยอิล 的问题相同）。同类：물렸어요 มุลลยอซอโย、안 열려요 อัน ย็อลลยอโย、부탁드려요 พูทักตือรยอโย。要不要定一个统一写法？
- [ko-B12-02] 짜장면 → จาจังมยอน：按通行写法（同 라면 รามยอน），不写 จาจังมย็อน。
- [ko-B12-03] 라볶이 → ราบกกี（仿通行的 ต็อกบกกี，学术院应为 ราโบกี）；족발 → ชกปัล（学术院 + 紧音化；ชก 在泰语是"打拳"，不粗俗；通行写法有 จกบัล）。
- [ko-B12-05] 김치찌개 → กิมจิจีแก（沿用 김치 例外）；된장찌개 → ทเว็นจังจีแก（约定 3：辅音 + เว）。
- [ko-B13-04] 서울 → โซล、부산 → ปูซาน：用泰国通用的地名写法（约定 1），不用 ซออุล、พูซัน。
- [ko-B13-03] 플랫폼 → พึลแล็ดพม；[ko-B16-04] 팝콘 → พับคน（拼出来像泰语"折 + 人"，不粗俗但有点怪）。保留吗？
- [ko-B14-01] 괜찮으세요? → แควนชานือเซโย（沿用 괜찮아요 แควนชานาโย）。
- [ko-B15-01] 실례합니다 → ชิลเลฮัมนีดา：按通行写法；标准音 [실례] 按学术院会写成 ชิลลเย…。
- [ko-B15-05] 잡채 → จับแช（通行写法，学术院为 ชับแช）；집밥 → ชิปปับ（避开 ชิบ，同 집 ชิป）。

## 词义

- 为了和后面阶段的词区分，改了三条词义：[ko-B13-03] 플랫폼 ชานชาลา (แพลตฟอร์ม)（区别于 승강장）、[ko-B15-03] 건배 ชนแก้ว! (คำพูดตอนดื่มฉลอง)（区别于 건배하다）、[ko-B16-r01] 엔딩 ฉากจบ, ตอนจบของหนัง（区别于 결말）。
