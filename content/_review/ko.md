# 韩语课（A、B 阶段）审校备注

AI 初稿，以下是拿不准、需要母语老师（韩语 / 泰语）确认的地方。泰文转写按皇家学术院（ราชบัณฑิตยสภา）韩语转写原则，从 RR 读音机械转写（词首 ㄱㄷㅂㅈ → ค ท พ ช，词中 → ก ด บ จ；开音节长元音，闭音节短元音：ㅓ → อ/็อ，ㅐ → แ/แ-็；收音 ㄹ → ล；ㅅ/ㅆ + ㅣ 或 y 类元音 → ช）。

- [ko-A1-01] 이 선생님（全课）：对话里按女性配音（speaker "c"），人物表没写老师性别，请确认。
- [ko-A1-01] 泰语译文：只有老师的台词用 จ้ะ（สวัสดีจ้ะ、ไม่เป็นไรจ้ะ）表示长辈对学生的亲切语气，其他角色不加句尾语气词。这个语域是否合适？
- [ko-A1-02] 안녕히 계세요 → อันนย็องฮี คเยเซโย：按学术院原则从 RR gyeseyo 转写；泰国教材常写 เกเซโย（实际多读 [게세요]）。保留学术院写法还是改用常见写法？（[ko-B6-01] 계세요 同）
- [ko-A1-03] 괜찮아요 → คแว็นชานาโย：带 w 的音节按"辅音 + แว็/เว/วา"写，看起来不自然（常见写法 แควนชานาโย）。同类：[ko-A3-02] 처음 뵙겠습니다 → ชออึม พเว็บเก็ดซึมนีดา，[ko-A3-04] 회사원 → ฮเวซาว็อน，[ko-B4-04] 왼쪽 → เว็นจก。保留还是改？
- [ko-A1-04] 잠깐만요：reading 写 jamkkanmanyo，泰文转写 ชัมกันมันโย；实际常读 [잠깐만뇨]（요 前添加 ㄴ），要不要按实际发音写？同类：씨는요、이거는요、형은요、바나나는요、오후에는요 的 reading 都写成 -neunyo（[ko-A3-03] 起）。
- [ko-A2-03] 가 / [ko-A4-02] 카：两者泰文转写都是 คา（学术院把词首 ㄱ 和 ㅋ 都写 ค），只靠词义 "เสียง คา (ㄱ+ㅏ)" / "เสียง คา พ่นลม (ㅋ+ㅏ)" 区分；다/타、바/파、자/차 同理。是否可以接受？
- [ko-A3-01] 씨 → ชี：把 ㅆ + ㅣ 按 ㅅ + ㅣ 处理写成 ช（学术院对 ㅅ + ㅣ 用 ช，如 신라 ชิลลา），ㅆ 是否也这样处理不确定。
- [ko-A3-04] 선생님, 친구 민준 씨예요.：介绍朋友时省略 제（제 친구），是否自然？
- [ko-A4-01] 시：词义写 "เสียง ชี (ㅅ+ㅣ)"，全课把 ㅅ + ㅣ 都转写成 ชี/ชิ（시간 ชีกัน、택시 แท็กชี、십 ชิบ、신발 ชินบัล、맛있어요 มาชีซอโย）。请确认符合学术院原则、不误导学习者。
- [ko-A4-04] ㅢ 的 say 写 의：请确认 TTS 单念读 [의] 而不是 [에]。
- [ko-A4-04] ㅐ/ㅔ、ㅚ/ㅙ/ㅞ：本课只出看字题（choose-meaning、choose-text），不出听音题；但复习（core 的 reviewSteps）对所有发音类词条都出 listen-text 并自动挑错误选项，可能把 ㅔ 当成 ㅐ 的错误选项（reading 不同、听起来一样）。需要开发在引擎里排除这类近音组。
- [ko-A5-02] 공일공, 이삼사오, 육칠팔구예요.：报电话号码时分组之间不加 에，是否自然？
- [ko-A6-02] 김치는 밥하고 먹어요 的 reading 写 baphago；[ko-A6-03] 숟가락하고 写 sutgarakhago；[ko-B6-03] 행복해요 写 haengbokhaeyo：按 RR"体词后 ㄱ/ㄷ/ㅂ + ㅎ 写出 h"处理，实际发音是 [바파고]、[행보캐요]。是否改成 bapago、haengbokaeyo？
- [ko-A6-03] 네, 숟가락하고 젓가락 여기요.：服务员递东西时这样说是否自然？
- [ko-B1-02] 앋、갇：为练收音 [t] 选的少见音节，请确认 TTS 读成 [앋]、[갇]。
- [ko-B1-02] 알 → อัล、갈 → คัล：泰国人会把词尾 ล 读成 น，转写表现不了 [l]，只靠讲解说明。可以吗？
- [ko-B2-01] 월요일 วอรโยอิล，[ko-B2-02] 일요일 อีรโยอิล、금요일 คือมโยอิล、목요일 โมกโยอิล，[ko-B4-02] 학교 ฮักกโย：连音后"辅音 + y"的学术院写法容易被泰国读者误读（วอร 读成 วอน）。保留还是改成常见写法（วอลโยอิล、อิลโยอิล、คึมโยอิล、มกโยอิล、ฮักเคียว）？
- [ko-B2-01] 무슨 요일이에요?：reading 按词写 museun yoirieyo，实际发音 [무슨뇨이리에요]（添加 ㄴ）。保留？
- [ko-B2-03] 유월 오일이에요 / 시월 구일이에요：日期用韩文写、"日"连写（구일），是否合适？还是改用数字（10월 9일）？
- [ko-B3-03] 카드 괜찮아요?：口语里 카드 돼요? 更常见，但 돼요 还没教。保留？
- [ko-B4-01] 편의점：reading pyeonuijeom（RR 保留 ui），转写 พยอนึยจ็อม；实际发音 [펴니점]，泰国常写 พยอนีจอม。保留？
- [ko-B5-03] 쉬어요 → ซวีออโย：ㅅ + ㅟ 没按 ช 处理，常见写法 ชวีออโย。哪个对？
- [ko-B6-01] 열일곱 살이에요：reading 按 [열릴곱 사리에요] 写 yeollilgop sarieyo，请确认。
