## Server API (implemented in server/src/app.ts — read it for exact shapes)
Base URL comes from `process.env.EXPO_PUBLIC_API_URL`; when unset the app must work fully offline exactly as today.
- POST /v1/accounts → 201 {id, token} (anonymous account per install)
- DELETE /v1/accounts/me → 204 (delete all server data)
- GET /v1/progress, PUT /v1/progress (body = core Progress; server merges with its copy and returns the merged Progress, which the device adopts)
- GET /v1/entitlements → {premium, premiumUntil}
- POST /v1/pronunciation, multipart: fields `target` (zh|en|ja|ko) and `text` (reference text, the item's `say ?? text`), then file field `audio` → {status: 'ok'|'no-speech', overall, accuracy, fluency, completeness, recognized, words: [{word, accuracy, error?}]}; 503 when scoring is not configured, 429 {error, limit} when the daily quota is used up.
- GET /audio/<path> serves generated speech clips; GET /legal/privacy-th.html, /legal/terms-th.html (and -en) are the legal pages.
All authenticated calls use `Authorization: Bearer <token>`.
