## 阶段 4：上线后 1–3 个月

- 看留存和付费指标（docs/PLAN.md §7），每月看一次 Azure、Anthropic、服务器账单和 RevenueCat 收入。
- 按用户反馈和母语老师意见改内容；AI 老师的举报邮件要处理。
- 常用词条、A 阶段对话换成真人录音（docs/AUDIO.md「以后换成真人录音」）。
- 按角色配声音（内容格式区分说话人性别）。
- 可能加的功能（方案里有、现在没做）：LINE 登录、模拟考、排行榜、离线下载。上线宣传里不能提还没有的功能。

## 阶段 5：扩张

- **新国家**（顺序见 docs/PLAN.md §2.4：越南 → 印尼 → 马来西亚 → 菲律宾 → 柬老缅）：`npm run l10n -- export --to vi` 导出翻译表 → 翻译界面、词义、译文、讲解（可以用智能体初译 + 当地老师审）→ `import` → 母语对照的发音讲解和泰文转写对应的注音 → `meta.json` 的 `released` 上架 → 当地定价、商店文案、法律页。
- **更高阶段**（G 以后，B2）：照 docs/prompts/ 的流水线：先写大纲 → `npm run plan:apply` → 写课 → 两轮审校 → 补词 → 情景对齐。
- 家庭版、儿童模式、学校版、价格 A/B 测试、投放（TikTok / KOL）。
