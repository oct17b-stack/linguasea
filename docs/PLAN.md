# 产品方案：给东南亚人学中文 / 英语 / 日语 / 韩语的订阅制 App

> 版本 v0.2 · 2026-10-22 · 草案，待确认
> 参考：仓库 [smallyjh-boop/taihaoshuo](https://github.com/smallyjh-boop/taihaoshuo)（泰好说），以及市场上成熟的语言学习 App。
> 文中的价格、市场数字都是估算或公开报价，上线前要用真实数据再核一遍。

---

## 1. 一句话定位

**用母语教东南亚人学中、英、日、韩四门语言的 App，从泰国起步。** 以 AI 口语陪练和发音打分为核心，课程对齐 HSK / CEFR / JLPT / TOPIK 考试等级，按订阅收费，上架 Google Play 和 App Store。

- **学的语言（目标语）**：中文、英语、日语、韩语，**四门一起开发**。
- **讲解用的语言（母语）**：先做泰语；架构从第一天起支持多母语，之后依次加越南语、印尼语、马来语、菲律宾语（他加禄语）、高棉语、老挝语、缅甸语等。

### 为什么能做得比泰好说好

泰好说的底子不错（课程流水线、FSRS 间隔复习、声调训练、AI 老师、家长报告），但它是**中文母语的孩子学泰语**，而且还停在家用阶段。我们要做的是另一个方向：

| | 泰好说 | 我们 |
|---|---|---|
| 学习者 | 说中文的孩子（10 岁、4 岁） | 东南亚的高中生、大学生、上班族（先泰国），以后加儿童模式 |
| 界面 / 讲解语言 | 中文 | **先泰语，再越南语、印尼语等**（多母语架构） |
| 学的语言 | 泰、日、英 | **中、英、日、韩** |
| 部署 | 家里 NAS + Tailscale | 云端，可扩容 |
| 苹果 | 只有网页版 | iOS 原生上架 |
| 收费 | 没有 | 订阅（Apple / Google 内购） |
| 配音 | edge-tts 免费声音，**不能商用** | 商用授权的 TTS + 关键内容真人录音 |
| 审校 | 基本是 AI 审校 | AI 初审 + 母语老师终审，作为上线门槛 |
| 考试 | 没有 | HSK / JLPT / TOPIK / CEFR 对齐，有模拟考 |

## 2. 市场与竞品

### 2.1 泰国用户想学什么

- **英语**：需求最大（升学、工作、旅游），但竞争也最激烈。
- **中文**：升学（中国奖学金、国际学校）、工作（中资企业、旅游业、电商）需求强，HSK 证书有实际用处。
- **日语**：动漫、旅游、日企，JLPT 证书有用。
- **韩语**：K-pop、韩剧带来的大量年轻用户，TOPIK 有用。

### 2.2 成熟产品，学它们什么

| 产品 | 强项 | 我们借鉴 |
|---|---|---|
| **Duolingo** | 游戏化（连胜、经验值、排行榜、宝石）、免费引流、Max 版 AI 视频通话 | 连胜 + 每日目标 + 联赛；免费版够用但有限制 |
| **Super Chinese / HelloChinese** | 专做中文，按 HSK 编排，AI 发音打分，有泰语界面版本 | HSK 对齐、汉字书写练习、拼音 → 汉字过渡 |
| **LingoDeer** | 专做亚洲语言（中日韩），语法讲得清楚 | 每课语法卡片、日韩文字系统教学 |
| **Cake** | 韩国 App，用短视频片段学口语，在泰国很火 | 用真实场景短片 / 对话片段做输入 |
| **Speak / Praktika** | AI 口语老师、角色扮演 | AI 对话是付费墙后的核心卖点 |
| **ELSA Speak** | 逐个音素的发音打分 | 发音评测（用云端发音评估接口） |
| **Busuu** | 母语者社区批改 | 第二期：写作 / 口语交给社区或老师批改 |
| **Ling** | 语种多，覆盖很多东南亚语言 | 注意：它也支持东南亚用户学外语，是直接对手之一 |

定价参考（2026 年公开报价，美元）：Speak 约 14.99/月，Praktika 约 8–12/月，Duolingo Max 约 29.99/月。泰国用户价格敏感，要按泰国区定价。

### 2.3 我们的差异化（说给用户听的）

1. **全程用母语讲解**（先泰语，后越南语、印尼语等），零基础也能看懂语法。
2. **一个订阅，四门语言**（竞品多数一门一个 App 或一门一个订阅）。
3. **利用母语本身的特点**：泰语、越南语、老挝语、缅甸语都有声调，教中文四声时直接和泰语五个声调类比；教日语高低音、韩语收音时也用泰语发音对照。这是外国 App 做不到的。
4. **母语文字转写辅助入门**（泰文 คำอ่าน、越南文、印尼文等拉丁转写），再逐步撤掉，过渡到拼音 / 假名 / 韩文字母。
5. **考试导向**：HSK 1–4、JLPT N5–N3、TOPIK I–II、英语 CEFR A1–B2，有模拟考和证书路线。
6. **AI 口语老师**在剧本范围内对话（泰好说的思路：剧本我们定，AI 在剧本里演），不会跑偏、教错。

### 2.4 东南亚扩张顺序

| 顺序 | 国家 | 母语 | 人口（约） | 说明 |
|---|---|---|---|---|
| 1 | 泰国 | 泰语 | 7,000 万 | 首发市场；泰语有声调，对中文四声有优势 |
| 2 | 越南 | 越南语 | 1 亿 | 学中文、日语、韩语需求都很强（日韩企业多）；越南语有声调、有大量汉越词，学中文有天然优势 |
| 3 | 印度尼西亚 | 印尼语 | 2.8 亿 | 东南亚最大市场；学英语、日语、韩语需求大，价格更敏感 |
| 4 | 马来西亚 | 马来语（+ 英语界面） | 3,400 万 | 华人多，中文需求强；付费能力较好 |
| 5 | 菲律宾 | 菲律宾语 / 英语 | 1.1 亿 | 英语较好，主学日语、韩语、中文 |
| 6 | 柬埔寨、老挝、缅甸 | 高棉语、老挝语、缅甸语 | 合计约 9,000 万 | 中文需求强（中资项目），付费能力弱，后做 |

每进一个国家要做：界面翻译、全部讲解 / 译文翻译、母语对照的发音讲解、母语老师审校、本地定价、本地商店素材、本地登录 / 社交渠道（泰国 LINE、越南 Zalo、印尼 WhatsApp 等）。

## 3. 用户与付费

### 3.1 目标用户（第一阶段）

- **主力**：15–35 岁泰国学生和上班族（后续扩到越南、印尼等国同年龄段），手机为主，有升学 / 工作 / 兴趣目标。
- **第二阶段**：儿童模式（家长付费，参考泰好说的家长报告、童趣皮肤、伙伴收集）。
- **第三阶段**：学校 / 企业版（按席位收费）。

### 3.2 收费模式：免费增值 + 订阅

| | 免费版 | Premium（订阅） |
|---|---|---|
| 课程 | 每门语言第一阶段全部 + 每天有限课数 | 全部阶段、全部语言 |
| 复习 | 有 | 有 + 错题本、薄弱点专练 |
| 发音打分 | 每天几次 | 无限 |
| AI 口语老师 | 体验 1–2 次 | 每天额度（控制成本） |
| 模拟考 | 无 | 有 |
| 离线下载 | 无 | 有 |
| 广告 | 可考虑少量（不建议首发就上） | 无 |

**建议首发价格（泰铢，待调研 + A/B 测试）：**

- 月付：约 ฿199–249
- 年付：约 ฿1,290–1,690（相当于月付 5–6 折，主推）
- 7 天免费试用（只给年付，转化最好）
- 家庭版（最多 6 人）：年付约 ฿2,490
- 以后可加：终身版（限时）、学生价
- **其他国家按当地购买力定价**（App Store / Google Play 都支持分国家定价），例如越南、印尼的价格应明显低于泰国，马来西亚可以略高。

**平台规则要注意：**

- iOS 和安卓的数字内容**必须走苹果 / 谷歌内购**，不能引导去外部付款。
- 两边对订阅都有 15% 小企业 / 订阅优惠费率（首年收入 100 万美元以内），否则 30%。上线前以官方最新条款为准。
- 泰国对境外数字服务征 7% 增值税，由商店代扣代缴，定价时算进去；越南、印尼、马来西亚等也有类似的数字服务税，各国定价时分别算。
- 订阅管理用 **RevenueCat**（统一 Apple / Google 订阅、试用、续费、退款、看板），自己不要从零写收据校验。

## 4. 学习设计

### 4.1 等级阶梯（每门语言 A–F 六个阶段）

| 阶段 | CEFR | 中文 | 日语 | 韩语 | 英语 | 主要形态 |
|---|---|---|---|---|---|---|
| A 入门 | pre-A1 | 拼音、声调、HSK1 前半 | 假名、N5 前半 | 韩文字母、TOPIK1 前半 | 字母、自然拼读 | 微课：听 → 点 → 说，泰文转写辅助 |
| B 基础 | A1 | HSK1–2 | N5 | TOPIK I（1 级） | A1 | 微课 + 短对话 + 认字 |
| C 进阶 | A2 | HSK3 | N4 | TOPIK I（2 级） | A2 | 完整对话、读短文、写句子 |
| D 中级 | B1 前 | HSK4 前 | N3 前 | TOPIK II（3 级前） | B1 前 | 故事、短文、AI 场景对话 |
| E 中级 | B1 | HSK4 | N3 | TOPIK II（3 级） | B1 | 文章、议论、写作 |
| F 中高级 | B2 前 | HSK5 前 | N2 前 | TOPIK II（4 级前） | B2 前 | 新闻、长文、开放 AI 对话 |

每门语言目标约 **200 小时**学习量（和泰好说一致），先把 A–C 做扎实再往后扩。

### 4.2 一节课的结构（参考泰好说的"课时"）

场景引入 → 点词学新词 → 听音选择 → 语法小卡（泰语讲解）→ 对话 / 角色扮演 → 跟读打分 → 综合练习 → 小测 → 奖励

题型要丰富，**不能只有"听音选图"**（泰好说复盘里最大的教训之一）：听选、看选、填空、排序、拼写 / 手写（汉字、假名、韩文）、听写、跟读、看图说、翻译、角色扮演。

### 4.3 各语言的特殊模块（做成"语言包"，引擎里不写死）

- **中文**：拼音和声调训练器（音高曲线对比，和泰语声调类比）、汉字笔顺书写、量词、HSK 词表。
- **日语**：平假名 / 片假名、汉字读音（音读 / 训读）、高低音、敬语。
- **韩语**：韩文字母拼读、收音（받침）、音变规则、敬语层级。
- **英语**：自然拼读、重音、连读、美式 / 英式选择。

### 4.4 留存（参考 Duolingo）

- 每日目标 + 连胜（可用"连胜保护"）
- 经验值、周联赛排行榜
- 推送提醒（根据用户常学时间）
- FSRS 间隔复习（泰好说已验证可行，用开源 `ts-fsrs`）
- 成就徽章、学完一段解锁角色 / 故事
- 分享学习成果到 LINE / Facebook / TikTok（泰国主流社交）

## 5. 技术方案

### 5.1 选型

| 部分 | 建议 | 理由 |
|---|---|---|
| App | **React Native + Expo**（TypeScript） | 一套代码出 iOS + 安卓；原生音频、录音、推送、内购都有成熟库；比泰好说的 Capacitor 网页壳更流畅，过苹果审核更稳 |
| 内购 | RevenueCat（`react-native-purchases`） | 见 3.2 |
| 后端 | Node.js（TypeScript）+ PostgreSQL | 用户、进度同步、订阅状态、AI 额度 |
| 账号 | 邮箱 / Google / **Apple 登录（iOS 上有第三方登录就必须有）** / LINE 登录 | LINE 在泰国是第一社交 |
| 内容 | JSON 课程包 + zod 校验 + 内容流水线（参考泰好说 `contract/` 的思路） | 内容和 App 分开发布，改课不用发版 |
| 存储 / 分发 | 对象存储 + CDN（课程 JSON、音频、图片） | 用户在泰国，选新加坡 / 曼谷节点 |
| 复习算法 | `ts-fsrs` | |
| 离线 | 本地 SQLite（expo-sqlite），课程包按单元下载 | |
| 数据分析 | PostHog / Firebase Analytics | 漏斗、留存、付费转化 |
| 崩溃监控 | Sentry | |
| CI / CD | GitHub Actions + EAS Build / EAS Submit | 自动出包、提交商店 |

### 5.2 多母语架构（关键，第一天就要做对）

课程内容拆成两层，**目标语内容只做一次，各国母语只做翻译和讲解层**：

```
courses/<目标语>/...            课程结构、课文、对话、词表、音频（zh / en / ja / ko，各国共用）
l1/<母语>/<目标语>/...           这门母语的讲解：译文、语法说明、发音对照、转写规则（th / vi / id / ms / fil ...）
l1/<母语>/ui.json               界面文字
```

- 引擎里不写死任何一门语言：目标语的特殊模块（声调、汉字、假名、韩文字母）和母语的特殊模块（泰文转写、越南语声调对照）都做成"语言包"。
- 每门母语 × 每门目标语 = 一个"课程组合"，缺讲解层的组合不上架；后台可按国家 / 母语开关。
- 用户第一次打开选：我的母语 → 我想学的语言（可多选，一个订阅全部可学）。
- 校验工具检查：每个课文句子在已上架的母语里都有译文、每个语法点都有讲解。
- 翻译流水线：AI 按术语表翻译 → AI 交叉审校 → 当地母语老师抽查 / 终审。

### 5.3 AI 与语音（商用授权）

| 功能 | 方案 | 备注 |
|---|---|---|
| 配音 TTS | Azure / Google Cloud TTS 商用版，或 ElevenLabs；主课文关键句可请真人录音 | **不能用 edge-tts 上线**（泰好说的坑） |
| 发音打分 | Azure Pronunciation Assessment（支持中英日韩） | 按次计费，免费版限次 |
| 语音识别 | 同上 / Whisper | |
| AI 口语老师 | 大模型（如 Claude）+ 剧本状态机 | 在剧本范围内对话；每日额度控成本；内容安全过滤 |
| AI 生成课程 | 大模型按规格批量出初稿 → AI 交叉审校 → **母语老师终审** | 母语审校是上线门槛 |

**成本要算清：** AI 对话和发音打分按量计费，必须给每个付费用户设每日额度，并在后台监控单用户成本，保证订阅收入覆盖。

### 5.4 安全与合规

- **各国个人信息法**：泰国 PDPA、越南个人数据保护法令、印尼 PDP 法、马来西亚 PDPA 等。隐私政策出各国语言版本、收集同意、数据删除入口；录音尽量不存或短期存。上新国家前查一遍当地要求（越南等对数据本地化有额外规定）。
- 苹果要求：App 内可删除账号；隐私标签如实填写；订阅页清楚写价格和自动续费说明；有"恢复购买"按钮。
- 儿童模式上线时：家长同意、不放广告、遵守商店儿童类别规则。
- 密钥不进仓库（`.env`、签名文件写进 `.gitignore`），密钥由你本人在后台 / CI 里填。
