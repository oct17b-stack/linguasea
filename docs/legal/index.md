# LinguaSEA — ช่วยเหลือ / Help

LinguaSEA เป็นแอปเรียนภาษาจีน อังกฤษ ญี่ปุ่น และเกาหลี พร้อมคำอธิบายภาษาไทย ให้บริการโดย [รอกรอก: ชื่อผู้ให้บริการตามกฎหมาย]

## ภาษาไทย

**ติดต่อเรา:** [รอกรอก: อีเมลติดต่อ]

- **ยกเลิกการสมัครสมาชิก:** iPhone/iPad: **การตั้งค่า** → ชื่อของคุณ → **การสมัครรับ** → **LinguaSEA** · Android: **Google Play Store** → รูปโปรไฟล์ → **การชำระเงินและการสมัครใช้บริการ** → **การสมัครใช้บริการ** → **LinguaSEA**
- **กู้คืนการซื้อ:** เปิดหน้าการสมัครสมาชิกในแอป แล้วแตะ **กู้คืนการซื้อ** (ใช้ Apple ID หรือบัญชี Google เดียวกับที่ใช้ซื้อ)
- **ขอคืนเงิน:** Apple และ Google เป็นผู้พิจารณาการคืนเงิน ดูข้อ 4.5 ใน[ข้อกำหนดการให้บริการ](terms-th.md)
- **ลบข้อมูล:** ในแอป **ตั้งค่า → ลบข้อมูลของฉัน** หรือดู[หน้าการลบข้อมูล](delete-account-th.md)
