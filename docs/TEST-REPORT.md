### 3.3 服务器（server/）

| 级别 | 问题 | 修复 |
|---|---|---|
| 高 | 限流完全没生效（路由在插件加载前注册），注册账号、验证码都能无限请求 | 路由放进限流之后注册的子插件；只限 `/v1/`，静态文件和配音不限 |
| 高 | 客户端能伪造 X-Forwarded-For 来换 IP，绕过所有按 IP 的限制 | 按代理跳数信任，新环境变量 `TRUST_PROXY`（默认 1，已写进 LAUNCH.md） |
| 高 | 验证码能并发暴力猜（先比对后计数） | 先原子计数再比对，超过 5 次直接拒绝 |
| 中 | `/v1/transcribe`（语音转文字）没有每日上限，可被刷 Azure 费用 | 每日配额 = AI 老师轮数 × 2（免费 12、付费 60） |
| 中 | RevenueCat 的 `SUBSCRIPTION_EXTENDED`、`TEMPORARY_ENTITLEMENT_GRANT`、`REFUND_REVERSED` 没处理（提前失去会员）；退款（`CANCELLATION` 带 `expiration_at_ms`）后还有会员 | 都处理了。**上线前用 RevenueCat 沙盒退款核对一次** |
| 低 | webhook 时间戳超范围时数据库报 500（RevenueCat 会一直重试） | 不合法返回 400 |
| 低 | 5xx 把数据库报错原样返回给客户端 | 只记日志，客户端收到 `internal error` |
| 低 | 上传不是 multipart 时报"太大" | 400 / 413 分开 |
| 低 | AI 老师对话记录可以用换行伪造老师的话；老师行不打码 | 每行压成单行，两种角色都打码 |
| 加固 | ffmpeg 可能被诱导去请求网址或读本地文件 | 限定 `file` 协议和音频格式白名单 |

### 3.4 内容和配音

- 中文"还"有两个词条：`zh.hai-still`（hái）和 `zh.huan-return`（huán）。配音清单按文字找录音，所以两个共用一段，"归还"会念成 hái。单独出现的"教"（jiāo）、"差"（chà）也容易念错。三个都加了 `say`（环、交、岔），只重新生成了这 3 段。

## 4. 测过没问题的

- **4.1 配音**：A、B 阶段四门课 7,800 段全部有文件（`npm run audio -- --stage A --stage B --dry-run` 显示 missing 0）。网页版 A、B 阶段的词、对话（按说话人换声音）、读物句子都播放 `/audio/` 下的 mp3，没有 404；（当时）C 阶段以后用设备 TTS，不请求音频。2026-10-29 更新：**四门课 A–F 配音全部生成**（39,565 段，`npm run audio -- --dry-run` 显示四门课 missing 0："Nothing missing: every clip has a file."）。每门课每个阶段生成后 `npm run check` 通过，没有小于 2 KB 的异常文件；全部生成后 `npm run e2e` 160/160 通过（第 8 节原来检查"C 阶段退回设备 TTS、不请求配音"，现在 C 阶段有配音了，改成检查 C 阶段播放生成的配音、服务器都返回 200/206、不用设备 TTS）。
- **4.2 界面**：没有横向溢出和截断的泰文，深色模式正常；没有控制台错误和意外的失败请求；没有麦克风权限时有提示。
- **4.3 引擎**：路径顺序和解锁、分级测试落点、App 用的进度百分比、FSRS（随机历史、一年的间隔）、730 天 × 6 个时区（含圣地亚哥午夜夏令时、豪勋爵岛半小时夏令时）、合并的交换律和幂等、`estimateHours`（每门约 230 小时）都正常。
- **4.4 内容**：泰文没有缺译、占位符、对话译文条数和读物题目都对得上；扫描报出的 10 处全是误报（对话里本来就是邮箱 / 电话号码、两人互相说"你好"、标题就是目标语单词、"长"和"只"是不同 id 的两个词）。`npm run validate`、`npm run dupes` 干净。
- **4.5 服务器**：路径穿越、JSON 原型污染、8MB 上限、匿名账号合并、别名账号收续费、TRANSFER、乱序事件、删除账号（两种存储逐表核对）、只登出当前设备、没配密钥时返回 503、CORS 预检。

## 5. 注意：测试也有盲区

- 只测了网页版。iOS / 安卓的录音、通知、应用内购买、恢复购买要在 EAS 内测版上用真机测（ROADMAP 阶段 3 第 10 步）。
- AI 老师、发音打分、邮件、RevenueCat 都是模拟的（没有真密钥）；拿到密钥后各测一次真的。
- 配音的发音对不对只能人听：请店主或母语老师抽听各阶段的多音字、人名、数字、日语汉字。
- 课程内容的语言质量只能靠母语老师终审（content/_review/）。

## 6. 发现但没修的（按优先级）

| 级别 | 问题 | 位置 / 建议 |
|---|---|---|
| 低 | 刷新页面会让正在上的课从头开始（课内进度不保存） | 产品取舍；端到端测试已把现状记下来 |
| 低（✅ 2026-10-29 已修） | 服务器调用失败（发音打分、AI 老师 502）也扣当天次数 | 加了 `Store.refundQuota`，打分、语音输入、AI 老师失败时退还 |
| 低 | 按邮箱 / IP 的验证码计数只在内存里，重启清零、多实例不共享；有人每小时请求 5 次就能让某个邮箱一小时登录不了 | 上线多实例时改存数据库 |
| 低（✅ 2026-10-29 已修） | 每日配额按服务器时区（UTC）切日，等于曼谷早上 7 点重置 | 改成按 `QUOTA_TIME_ZONE`（默认 Asia/Bangkok）的午夜切日 |
| 低（✅ 2026-10-29 已修） | `/audio/<课程>/manifest.json` 也带一年缓存，但它不是按哈希命名的 | 只有 16 位哈希命名的 mp3 永久缓存，manifest 和真人录音缓存 5 分钟 |
| 低 | 静态目录会提供以点开头的文件（如 `/audio/.gitkeep`） | 留着是为了以后 `/.well-known/`（通用链接） |
| 低（✅ 2026-10-29 已修） | 进度里卡片的 `due` 可以是任意字符串（只会弄坏用户自己的数据） | 服务器要求 ISO 时间（`toISOString()` 的格式） |
| 低 | 限流 `POST /v1/accounts` 每 IP 每小时 20 次，泰国运营商 CGNAT 下很多人共用 IP，可能偏紧 | 上线前评估，必要时调大 |

| 配音（✅ 2026-10-26 已处理） | 中文"长"（cháng / zhǎng）、"只"（zhī / zhǐ）和"还"一样是同字不同音的两个词条；已给 zh.zhang-grow、zh.zhi-measure 加 `say`，另给 C–F 单念易错的 11 个词加了 `say`。还剩 `zh.dei`（得 děi）没有合适的同音字，要人听 | `content/courses/zh/lessons/` |
