# 课程内容编写规范

写课、改课、审课都按这份来。格式由 `packages/contract/src/schema.ts` 定义，`npm run validate`（或 `npm run validate -- --target zh` 只看一门）必须零问题。

## 1. 文件

```
content/courses/<目标语>/course.json              课程结构：阶段 → 单元 → 课
content/courses/<目标语>/lessons/<课号>.json       一节课的目标语内容（各国共用）
content/l1/th/<目标语>/course.json                 泰语：课程名、阶段名、单元名和目标
content/l1/th/<目标语>/lessons/<课号>.json         泰语：课题、导语、词义、注音、对话译文、讲解
content/_review/<目标语>*.md                       给母语老师的审校备注（拿不准的地方；终审做法见 content/_review/README.md）
```

- 课号 `zh-A3-02`：语言-阶段+单元号-课序号。单元号 `zh-A3` = A 阶段第 3 单元。
- 目标语 `course.json` 的每个单元可以带 `scenario`：AI 老师在这个单元扮演的情景（英文，各国共用），写清 B 是谁、学习者（A，ナム／남／Nam／小南）要完成什么，例如 `B is a pharmacist. Nam says where it hurts and asks how often to take the medicine.`。来自大纲（`npm run plan:apply` 会写进去），AI 老师按它开场和收尾。
- 词条 id `zh.ni-hao`：语言 + 小写拼音/罗马字，连字符分隔；同音不同词加后缀（`zh.ta-he`、`zh.ta-she`）。
- 写法和读音都相同、意思不同的两个词（日语 さん「先生／小姐」和 さん「三」）各用一个 id，并在目标语 `course.json` 的 `homonyms` 里成组列出（`[["ja.san-honorific", "ja.san"]]`），`npm run dupes` 就不会把它们当成同一个词的两个 id。
- **id 一旦发布就永远不改**（复习卡片靠它）。同一个词在不同课里重复出现时用同一个 id，文字、读音、kind 必须完全一样；词义只在第一次出现的课里讲。
- 第一次公开发布前（现在）可以随意调整。

## 2. 一节课（目标语层）

```json
{
  "id": "zh-A3-01", "target": "zh", "stage": "A", "minutes": 5,
  "items": [
    { "id": "zh.wo", "text": "我", "reading": "wǒ" },
    { "id": "zh.jiao", "text": "叫", "reading": "jiào" },
    { "id": "zh.wo-jiao", "kind": "phrase", "text": "我叫……", "reading": "wǒ jiào……" }
  ],
  "dialogue": [
    { "speaker": "a", "text": "你好！我叫小南。", "reading": "Nǐ hǎo! Wǒ jiào Xiǎonán." },
    { "speaker": "b", "text": "你好！我叫王明。", "reading": "Nǐ hǎo! Wǒ jiào Wáng Míng." }
  ]
}
```

- `kind`：`word`（默认）、`phrase`（短语/整句）、`letter`（字母、假名）、`syllable`（音节、带声调的拼音）。题目按 kind 分组出：词汇题的错误选项只从词汇里挑，发音题只从发音里挑。
- `say`：文字不能直接念的时候给配音用的文字。拼音 `mā` → `"say": "妈"`；韩文辅音练习用音节，不用单独的 ㄱ。所选汉字/音节单独念时的读音必须和 `reading` 完全一致（声调也一样）。
- `exercises`：**一般不写**，系统按标准组合自动出题（看字选义、听音选义、看义选字、跟读；发音类先听音选字再看字选读音）。只有需要指定错误选项时才写，例如声调和最小对立组：
  ```json
  "exercises": [
    { "type": "listen-text", "item": "zh.ma1", "options": ["zh.ma2", "zh.ma3", "zh.ma4"] },
    { "type": "listen-text", "item": "en.think", "options": ["en.sink"] }
  ]
  ```
  写了 `exercises` 就只出写的这些题，标准组合不再自动加，所以要把需要的题都写全（每个词至少一道选择题 + 全课 1–2 道 `speak`）。
  类型：`choose-meaning` 看字选义 · `listen-choose` 听音选义 · `choose-text` 看义选字 · `listen-text` 听音选字 · `speak` 跟读。
  只靠听的题（`listen-*`）里，错误选项不能和正确答案同音（校验器会查 `reading`）。
- `dialogue`：说话人只用 `a`（学习者一方，见下面的人物表）、`b`（对方是男性）和 `c`（对方是女性，如 ゆき、Emma）——配音按这个选男声或女声。对话只用本课和之前学过的词，加少量最基本的虚词。A 阶段每句 ≤ 8 个词（中文 ≤ 10 个字），B 阶段 ≤ 12 个词。2–8 句。纯字母/发音课可以没有对话。
- 每课 4–6 个词条（字母、假名课可到 12 个；课文里用到却没教过的基础词，可以作为第 7 个词条补进它第一次出现的那课，这课的 `minutes` 比本阶段标准多 1），5–8 分钟。

`reading` 规范：
- 中文：带调号的汉语拼音，按词连写（`nǐ hǎo`、`Wáng Míng`），句首和专名大写，标点照抄。轻声不标调（`xièxie`）。写本调，变调规则在讲解里说明。
- 日语：赫本式罗马字，长音用长音符号（`arigatō`、`sū`），助词 は/へ/を 写 `wa/e/o`，词间空格。日文正文 A–D 阶段按词组加空格（わかちがき，方便初学者），E 阶段起照正常日文书写、不加空格；汉字只用课程里已经以汉字教过的词，其余写假名。
- 韩语：文化观光部 2000 年《国语的罗马字表记法》（Revised Romanization），按实际发音（`gamsahamnida`）。
- 英语：美式 IPA，不加斜线（`həˈloʊ`）。

人物表（四门课共用一个主角，对话里保持一致）：

| | 中文 | 日语 | 韩语 | 英语 |
|---|---|---|---|---|
| 主角（a）：泰国大学生 น้ำ，20 岁，来自曼谷 | 小南 Xiǎonán | ナム Namu | 남 Nam | Nam |
| 好朋友 | 王明 Wáng Míng（男，北京人，`b`） | たなか ゆき Tanaka Yuki（女，`c`） | 김민준 Gim Minjun（男，`b`） | Emma（女，加拿大人，`c`） |
| 老师 | 李老师 Lǐ lǎoshī（女，`c`） | やまだせんせい Yamada sensei（男，`b`） | 이 선생님 I seonsaengnim（女，`c`） | Mr. Brown（男，`b`） |

主角 น้ำ 的固定设定（四门课一致）：**女生**；四口之家——爸爸、妈妈（都是老师，住在曼谷）、妹妹 ฟ้า（Fah，A 阶段时 17 岁，高中生）和自己；生日 6 月 5 日；在曼谷读大学，周末在一家餐厅打工。人物表里的年龄（น้ำ 20 岁、ฟ้า 17 岁）是 A 阶段时的；故事会往后走两三年，后面的阶段不要再写具体岁数。

- 性别要体现在：她的台词的泰语译文用 ฉัน（不用 ผม）；中文第三人称用 她，英语用 she / her；韩语里她管年长的女性朋友叫 언니、男性朋友叫 오빠；日语自称 わたし。四门课的 `a` 配音都是女声。
- 故事线：A–B 阶段她在曼谷。C 阶段起各门课按自己的大纲让她去目标语国家留学或交换（先住宿舍，后来租房等，以大纲为准），在那边打工、实习都可以；上面的家人、生日等固定设定始终不变。

店员、司机等路人可以随意设定，但不要再新增固定角色。

## 3. 泰语讲解层

```json
{
  "lesson": "zh-A3-01",
  "title": "แนะนำตัวเอง",
  "intro": "บอกชื่อตัวเองและถามชื่อคนอื่นเป็นภาษาจีน",
  "items": {
    "zh.wo": { "meaning": "ฉัน", "translit": "หว่อ" },
    "zh.jiao": { "meaning": "ชื่อ (เรียกว่า)", "translit": "เจี้ยว" },
    "zh.wo-jiao": { "meaning": "ฉันชื่อ……", "translit": "หว่อ เจี้ยว" }
  },
  "dialogue": ["สวัสดี! ฉันชื่อน้ำ", "สวัสดี! ฉันชื่อหวังหมิง"],
  "notes": [{ "title": "叫 กับการบอกชื่อ", "body": "ภาษาจีนใช้ 我叫 + ชื่อ ……" }]
}
```

- `meaning`：简短自然的泰语。同一门课里不同词条的意思要能区分（`เขา (ผู้ชาย)` / `เขา (ผู้หญิง)`）。发音类词条写读法说明，如 `เสียง อะ`、`เสียงที่ 1 (ระดับสูง)`。
- `translit`：A、B 阶段每个词条都要有，用泰文写近似读音。
  - 中文：泰国教材常用写法，用泰文声调符号表示近似声调（你好 หนี่ห่าว、谢谢 เซี่ยเซีย）。
  - 日语、韩语：按泰国皇家学术院（ราชบัณฑิตยสภา）的转写原则（こんにちは คนนิจิวะ、안녕하세요 อันนย็องฮาเซโย）。
  - 英语：泰国常见的外来词写法（Hello เฮลโล）。
- `dialogue`：每句对话一条自然的泰语译文，顺序一致。
- `notes`：1–3 条，每条 1–3 句。讲本课最关键的一点（语法、发音、文化），**尽量拿泰语做对比**（泰语有声调、有量词、句尾有 ครับ/ค่ะ 等）。
- 文风：中性、亲切、简短，不用 ครับ/ค่ะ；像好老师在旁边点一句。
- `course.json` 里每个单元写 `title` 和 `goal`（学完能做什么，如 `ทักทายและขอบคุณได้`），每个阶段写 `title` 和 `description`。

## 4. 课程大纲（A–F 六个阶段，每门约 200 小时）

### 4.1 结构

每门课 6 个阶段，**每个阶段 16 个单元 × 6 课**（课号 01–06），一个单元一个话题；B–F 阶段每个单元还有分级读物（课号 r01、r02）。单元 = 一个话题 = 一个 AI 口语情景。

| 阶段 | CEFR | 中文 | 日语 | 韩语 | 英语 | 每课分钟 | 读物/单元 | 读物长度 | 累计词汇 |
|---|---|---|---|---|---|---|---|---|---|
| A 入门 | pre-A1 | HSK 1 | JLPT N5 | TOPIK I 1 级 | pre-A1 | 6 | 0 | — | ≈ 350 |
| B 基础 | A1 | HSK 1 | JLPT N5 | TOPIK I 1 级 | A1 | 7 | 1（8 分钟） | 4–6 句 | ≈ 800 |
| C 初级 | A2 | HSK 2 | N4 前半 | TOPIK I 2 级 | A2 | 8 | 2（10 分钟） | 6–10 句 | ≈ 1,300 |
| D 初中级 | A2+ | HSK 3 | N4 | TOPIK I 2 级 | A2+ | 9 | 2（12 分钟） | 8–14 句 | ≈ 1,900 |
| E 中级 | B1 | HSK 3–4 | N3 前半 | TOPIK II 3 级 | B1 | 10 | 2（14 分钟） | 10–18 句 | ≈ 2,500 |
| F 中级+ | B1+ | HSK 4 | N3 | TOPIK II 3 级 | B1+ | 11 | 2（15 分钟） | 14–24 句 | ≈ 3,000 |

- 课的 `minutes` 按上表写（学一课的真实时间：学词、对话、讲解、练习、跟读）。
- 每课 4–6 个新词条；对话随阶段加长：A ≤ 4 句，B 4–6，C 6–8，D 8–10，E–F 8–12；每课 1–3 条讲解，C 以后每课至少 1 条语法。
- A–B 已写好的单元 1–6（各 4 课）补到 6 课（05、06），再加单元 7–16；C–F 全部新写。
- 每门课的完整大纲（单元话题、每课主题、语法点、每课生词的 id/文字/读音）先由规划写进 `content/_plan/<目标语>.json`，写课时按大纲来，保证全课程不重复、循序渐进。C 阶段前 6 个单元可参考下面的话题。

### 4.4 分级读物（readers）

课号 `<单元>-r01`，`"kind": "reader"`，和课一样列在 course.json 的单元里（放在该单元的课后面）。

```json
{
  "id": "zh-C1-r01", "kind": "reader", "target": "zh", "stage": "C", "minutes": 10,
  "items": [ { "id": "zh.zhou-mo", "text": "周末", "reading": "zhōumò" } ],
  "passage": [
    [ { "text": "周末小南去公园。", "reading": "Zhōumò Xiǎonán qù gōngyuán." } ],
    [ { "text": "她在公园跑步。", "reading": "Tā zài gōngyuán pǎobù." } ]
  ],
  "questions": [ { "answer": 1 } ]
}
```

泰语层对应写 `passage`（同样的段落/句子结构，每句一条译文）和 `questions`（`prompt` + 2–4 个 `options`，`answer` 是正确选项的位置，从 0 数）。

- 正文只用学过的词，生词（3–6 个）放进 `items`，这些就是读物的生词表。
- 体裁轮换：小故事、日记、短信/邮件、通知、对话体短文、介绍文；人物沿用人物表，内容和本单元话题相关。
- 2–4 道阅读题考理解（谁、什么、为什么），不要考原句照抄。

## 5. 审校

写完后另一位审校（AI 初审，上线前必须由母语老师终审）逐条核对：读音和声调、泰语意思和注音、对话是否自然、是否超纲、讲解是否准确。拿不准的写进 `content/_review/<目标语>.md`，格式：`- [课号] 词条/句子：问题`。

## 6. 学习时长怎么算

`npm run hours` 按下面的口径给出每门课、每个阶段的估算（代码：`packages/core/src/hours.ts`）：

- 课和读物：按各自的 `minutes`。
- 练习课：每 2 课（读物也算）自动生成 1 节，每节 10 分钟。
- 单元测验：每单元 1 次，12 分钟。
- AI 口语情景：每单元 1 次，10 分钟（需要开通 AI 老师）。
- 间隔复习：课 + 读物 + 练习课时间的 15%。

按 4.1 的结构，每门课约 230 小时（不算 AI 口语约 214 小时）。目标：第一期每门课 ≥ 200 小时。
