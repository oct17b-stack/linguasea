# 课程内容编写规范

写课、改课、审课都按这份来。格式由 `packages/contract/src/schema.ts` 定义，`npm run validate`（或 `npm run validate -- --target zh` 只看一门）必须零问题。

## 1. 文件

```
content/courses/<目标语>/course.json              课程结构：阶段 → 单元 → 课
content/courses/<目标语>/lessons/<课号>.json       一节课的目标语内容（各国共用）
content/l1/th/<目标语>/course.json                 泰语：课程名、阶段名、单元名和目标
content/l1/th/<目标语>/lessons/<课号>.json         泰语：课题、导语、词义、注音、对话译文、讲解
content/_review/<目标语>.md                        给母语老师的审校备注（拿不准的地方）
```

- 课号 `zh-A3-02`：语言-阶段+单元号-课序号。单元号 `zh-A3` = A 阶段第 3 单元。
- 词条 id `zh.ni-hao`：语言 + 小写拼音/罗马字，连字符分隔；同音不同词加后缀（`zh.ta-he`、`zh.ta-she`）。
- **id 一旦发布就永远不改**（复习卡片靠它）。同一个词在不同课里重复出现时用同一个 id，文字、读音、kind 必须完全一样；词义只在第一次出现的课里讲。
- 第一次公开发布前（现在）可以随意调整。

## 2. 一节课（目标语层）

```json
{
  "id": "zh-A3-01", "target": "zh", "stage": "A", "minutes": 5,
  "items": [
    { "id": "zh.wo", "text": "我", "reading": "wǒ" },
    { "id": "zh.jiao", "text": "叫", "reading": "jiào" },
    { "id": "zh.wo-jiao", "kind": "phrase", "text": "我叫……", "reading": "wǒ jiào……" }
  ],
  "dialogue": [
    { "speaker": "a", "text": "你好！我叫小南。", "reading": "Nǐ hǎo! Wǒ jiào Xiǎonán." },
    { "speaker": "b", "text": "你好！我叫王明。", "reading": "Nǐ hǎo! Wǒ jiào Wáng Míng." }
  ]
}
```

- `kind`：`word`（默认）、`phrase`（短语/整句）、`letter`（字母、假名）、`syllable`（音节、带声调的拼音）。题目按 kind 分组出：词汇题的错误选项只从词汇里挑，发音题只从发音里挑。
- `say`：文字不能直接念的时候给配音用的文字。拼音 `mā` → `"say": "妈"`；韩文辅音练习用音节，不用单独的 ㄱ。所选汉字/音节单独念时的读音必须和 `reading` 完全一致（声调也一样）。
- `exercises`：**一般不写**，系统按标准组合自动出题（看字选义、听音选义、看义选字、跟读；发音类先听音选字再看字选读音）。只有需要指定错误选项时才写，例如声调和最小对立组：
  ```json
  "exercises": [
    { "type": "listen-text", "item": "zh.ma1", "options": ["zh.ma2", "zh.ma3", "zh.ma4"] },
    { "type": "listen-text", "item": "en.think", "options": ["en.sink"] }
  ]
  ```
  写了 `exercises` 就只出写的这些题，标准组合不再自动加，所以要把需要的题都写全（每个词至少一道选择题 + 全课 1–2 道 `speak`）。
  类型：`choose-meaning` 看字选义 · `listen-choose` 听音选义 · `choose-text` 看义选字 · `listen-text` 听音选字 · `speak` 跟读。
  只靠听的题（`listen-*`）里，错误选项不能和正确答案同音（校验器会查 `reading`）。
- `dialogue`：说话人只用 `a`（学习者一方，见下面的人物表）和 `b`（对方）。对话只用本课和之前学过的词，加少量最基本的虚词。A 阶段每句 ≤ 8 个词（中文 ≤ 10 个字），B 阶段 ≤ 12 个词。2–8 句。纯字母/发音课可以没有对话。
- 每课 4–6 个词条（字母、假名课可到 12 个），5–8 分钟。

`reading` 规范：
- 中文：带调号的汉语拼音，按词连写（`nǐ hǎo`、`Wáng Míng`），句首和专名大写，标点照抄。轻声不标调（`xièxie`）。写本调，变调规则在讲解里说明。
- 日语：赫本式罗马字，长音用长音符号（`arigatō`、`sū`），助词 は/へ/を 写 `wa/e/o`，词间空格。
- 韩语：文化观光部 2000 年《国语的罗马字表记法》（Revised Romanization），按实际发音（`gamsahamnida`）。
- 英语：美式 IPA，不加斜线（`həˈloʊ`）。

人物表（四门课共用一个主角，对话里保持一致）：

| | 中文 | 日语 | 韩语 | 英语 |
|---|---|---|---|---|
| 主角（a）：泰国大学生 น้ำ，20 岁，来自曼谷 | 小南 Xiǎonán | ナム Namu | 남 Nam | Nam |
| 好朋友 | 王明 Wáng Míng（男，北京人） | たなか ゆき Tanaka Yuki（女） | 김민준 Gim Minjun（男） | Emma（女，加拿大人） |
| 老师 | 李老师 Lǐ lǎoshī | やまだせんせい Yamada sensei | 이 선생님 I seonsaengnim | Mr. Brown |

店员、司机等路人可以随意设定，但不要再新增固定角色。

## 3. 泰语讲解层

```json
{
  "lesson": "zh-A3-01",
  "title": "แนะนำตัวเอง",
  "intro": "บอกชื่อตัวเองและถามชื่อคนอื่นเป็นภาษาจีน",
  "items": {
    "zh.wo": { "meaning": "ฉัน", "translit": "หว่อ" },
    "zh.jiao": { "meaning": "ชื่อ (เรียกว่า)", "translit": "เจี้ยว" },
    "zh.wo-jiao": { "meaning": "ฉันชื่อ……", "translit": "หว่อ เจี้ยว" }
  },
  "dialogue": ["สวัสดี! ฉันชื่อน้ำ", "สวัสดี! ฉันชื่อหวังหมิง"],
  "notes": [{ "title": "叫 กับการบอกชื่อ", "body": "ภาษาจีนใช้ 我叫 + ชื่อ ……" }]
}
```

- `meaning`：简短自然的泰语。同一门课里不同词条的意思要能区分（`เขา (ผู้ชาย)` / `เขา (ผู้หญิง)`）。发音类词条写读法说明，如 `เสียง อะ`、`เสียงที่ 1 (ระดับสูง)`。
- `translit`：A、B 阶段每个词条都要有，用泰文写近似读音。
  - 中文：泰国教材常用写法，用泰文声调符号表示近似声调（你好 หนี่ห่าว、谢谢 เซี่ยเซีย）。
  - 日语、韩语：按泰国皇家学术院（ราชบัณฑิตยสภา）的转写原则（こんにちは คนนิจิวะ、안녕하세요 อันนย็องฮาเซโย）。
  - 英语：泰国常见的外来词写法（Hello เฮลโล）。
- `dialogue`：每句对话一条自然的泰语译文，顺序一致。
- `notes`：1–3 条，每条 1–3 句。讲本课最关键的一点（语法、发音、文化），**尽量拿泰语做对比**（泰语有声调、有量词、句尾有 ครับ/ค่ะ 等）。
- 文风：中性、亲切、简短，不用 ครับ/ค่ะ；像好老师在旁边点一句。
- `course.json` 里每个单元写 `title` 和 `goal`（学完能做什么，如 `ทักทายและขอบคุณได้`），每个阶段写 `title` 和 `description`。

## 4. 课程大纲（A、B 两个阶段，每门 12 个单元 × 4 课）

A 阶段免费，B 阶段要订阅。考试对照：中文 HSK 1，日语 JLPT N5，韩语 TOPIK I（1 级），英语 CEFR pre-A1 → A1。选词优先用考试大纲里的常用词。

| 单元 | 中文 zh | 日语 ja | 韩语 ko | 英语 en |
|---|---|---|---|---|
| A1 | 打招呼、礼貌用语 | 打招呼、礼貌用语 | 打招呼、礼貌用语 | 打招呼、礼貌用语 |
| A2 | 拼音与声调（四声；声母；韵母） | 平假名 1（あ か さ た な 行） | 韩文字母 1（基本元音 + ㄱㄴㄷㄹㅁ） | 泰国人难发的音（th、v/w、r/l、sh/s、词尾辅音） |
| A3 | 自我介绍 | 自我介绍 | 自我介绍 | 自我介绍 |
| A4 | 数字 0–10、年龄 | 平假名 2（は ま や ら わ 行、を、ん） | 韩文字母 2（其余辅音、送气音、紧音、复合元音） | 数字 1–20、年龄 |
| A5 | 家人 | 数字、年龄 | 数字（汉字词和固有词）、年龄 | 家人 |
| A6 | 吃喝 | 吃喝 | 吃喝 | 吃喝 |
| B1 | 时间、日期、星期 | 平假名 3（浊音、半浊音、促音、拗音、长音） | 收音（받침）和连音 | 时间、日期、星期 |
| B2 | 买东西、价钱 | 片假名（外来词） | 时间、日期、星期 | 买东西、价钱 |
| B3 | 地点、方位 | 时间、日期、星期 | 买东西、价钱 | 地点、问路 |
| B4 | 日常作息 | 买东西、价钱 | 地点、交通 | 日常作息（一般现在时） |
| B5 | 天气、感受 | 地点、交通 | 日常作息 | 天气、感受 |
| B6 | 交通、出行 | 日常作息、家人 | 家人、感受 | 交通、出行 |

各语言的特别要求：
- 中文：A2 每个音节词条用 `say` 给一个单念时读音完全相同的汉字；四声用 `listen-text` + `options` 做成"听音选调"。B 阶段可以逐步不再依赖泰文注音，但现在仍然都写。
- 日语：A 阶段只用平假名（必要的人名、国名可用片假名）；B2 系统教片假名；B 阶段可以出现少量 N5 汉字，`reading` 照常写罗马字。
- 韩语：字母课用音节（가 나 다）和元音字母（ㅏ，`say` 写 아）练习；B1 讲收音和连音。
- 英语：A2 用最小对立组（think/sink、vest/west、right/light、she/see、rice/rise…）做 `listen-text` + `options`。

## 5. 审校

写完后另一位审校（AI 初审，上线前必须由母语老师终审）逐条核对：读音和声调、泰语意思和注音、对话是否自然、是否超纲、讲解是否准确。拿不准的写进 `content/_review/<目标语>.md`，格式：`- [课号] 词条/句子：问题`。
